## 🌟 Key Interactive Features & Architecture

### 1. 🎯 Onboarding Role Track Selection Gateway
* Visitors and hiring managers are greeted with an interactive role selection modal to choose their customized evaluation track:
  * **🛡️ Track 1: Cloud Security & DevSecOps Lead** (Volkswagen AI Security, Sentinel SIEM/SOAR, Defender for Cloud, Shift-Left SAST/DAST)
  * **⚡ Track 2: Azure & Multi-Cloud DevOps Architect** (Azure DevOps, Terraform IaC, ArgoCD GitOps, 70+ App Migrations, AKS & .NET Automation)
  * **🌐 Track 3: Unified Dual Mastery** (Full synergy of high-velocity delivery pipelines hardened with zero-trust security from day one)
* Automatically adapts headlines, metrics, ambient lighting, and pre-selects the corresponding CV for download.

### 2. 🌀 3D Video Frame Sequence Canvas Scrubber
* Powered by 192 high-definition frames rendered on an HTML5 `<canvas>` buffer:
* **Manual Scrubbing**: Timeline slider allowing instant inspection from frame 001 to 192.
* **Direct 3D Drag**: Click/touch and drag to rotate the 3D model 360 degrees.
* **Auto-Spin & Speed Controls**: Smooth 24 FPS playback with `1x`, `2x`, and `0.5x` playback speeds.
* **HUD Telemetry**: Live display of real-time azimuth angle, frame index, and cloud defense status tags.

### 3. ⚖️ "DevOps Velocity × Cloud Security Defense" Synergy Matrix
* Side-by-side interactive comparison across 4 enterprise domains:
  1. **CI/CD & Release Automation**: Multi-stage Azure Pipelines vs Snyk/Checkmarx Shift-Left Gating.
  2. **Infrastructure as Code**: Modular Terraform Cloud & AWS Landing Zones vs Azure Policy-as-Code & IAM Boundaries.
  3. **Containers & Orchestration**: Production AKS Cluster Lifecycle vs Calico NetworkPolicies & Container Hardening.
  4. **Operations & AI**: IIS 8.5/10 & Web Transforms vs Microsoft Sentinel KQL Hunting & Autonomous AI Triage.

### 4. 🧪 Shift-Left DevSecOps CI/CD Pipeline Simulator
* Interactive test runner simulating an enterprise delivery pipeline:
  * **Stage 1**: Git Checkout & Linting
  * **Stage 2**: Snyk & Checkmarx SAST/SCA Analysis
  * **Stage 3**: GitGuardian Secrets Scanning & Azure Key Vault Verification
  * **Stage 4**: Trivy Container Image Hardening & Signing

  * **Stage 6**: ArgoCD GitOps Deployment to Azure Kubernetes Service (AKS)
* Supports **"Run Clean"** and **"Test Threat Gate"** modes with animated streaming terminal logs.

## 💻 Getting Started Locally

### Prerequisites
* **Node.js**: v18.0.0 or higher (v20+ recommended)
* **npm**: v9.0.0 or higher

### Installation

1. **Clone or open the workspace directory**:
   ```bash
   cd f:\Portfolio
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Start the development server**:
   ```bash
   npm run dev
   ```
   *Open [http://localhost:3000](http://localhost:3000) in your browser.*

4. **Build for production**:
   ```bash
   npm run build
   ```
   *The optimized production output will be generated in the `dist/` directory.*

5. **Preview production build locally**:
   ```bash
   npm run preview
   ```
